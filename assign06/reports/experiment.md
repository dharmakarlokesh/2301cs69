# Assignment 6 — experiment report

Generated by `python -m p2p experiment`: 5 nodes on localhost TCP, each with 20–80 ms of artificial latency plus jitter. Structured logs (one JSON object per line with `ts`, `node`, `peer`, `object`, `event`) are in `reports/logs/node*.jsonl`.


## 1. Peer discovery

- Nodes 1–4 were only told about the seed `node0`. Through `getaddr`/`addr` every node discovered the others and the network became a **full mesh** (each node has 4 peers) in 0.71s.

## 2. Transaction and block relay (inventory first)

- node0 mined 3 blocks paying Alice; all nodes are at height 3 (tips {'000618729d'}).
- Alice's payment `71f44941283f` was submitted to node3 and reached every mempool via `inv` → `getdata` → `tx`.
- node1 mined it into block `00073a471e`; every node connected the block and removed the tx from its mempool.
- Relay order seen at node2 for that block: `recv-inv` from node1 → `recv-block` from node1 → `recv-inv` from node3. The full block is only sent after the peer asks for it.

## 3. Partition into {node0,node1} and {node2,node3,node4}

- Cross-group connections closed. Peers: node0=['node1'], node1=['node0'], node2=['node3', 'node4'], node3=['node2', 'node4'], node4=['node2', 'node3']
- Side X mempools: tx_x `6136a87de50d` (Alice→Carol) and tx_conf `ee39a181f467` (Alice→Dave, coin #3). Side Y mempools: tx_y `9707c88c36bf` (Alice→Erin, **the same coin #3**).
- One block mined on each side: X1 `000b5a150d` (contains tx_x and tx_conf) and Y1 `0009c79152` (contains tx_y). Equal height, so the network **disagrees**: tips = ['000b5a150d', '000b5a150d', '0009c79152', '0009c79152', '0009c79152']
- An additional block Y2 `0005879c76` is mined on side Y, which now has more work.

## 4. Heal the partition: reconnection and convergence

- Connections re-established in 0.45s; all nodes converged on Y2 `0005879c76` in 0.56s (tips {'0005879c76'}).
- node0 reorganised: disconnected ['000b5a150dcc'], connected ['0009c7915202', '0005879c76cb']. Stale-block txs reconsidered: `tx:ee39a181f467` → **dropped** (missing-or-spent-input), `tx:6136a87de50d` → **re-added** (accepted)
- node1 reorganised: disconnected ['000b5a150dcc'], connected ['0009c7915202', '0005879c76cb']. Stale-block txs reconsidered: `tx:ee39a181f467` → **dropped** (missing-or-spent-input), `tx:6136a87de50d` → **re-added** (accepted)
- tx_x (still valid) is back in **every** mempool, re-announced to side Y. tx_conf conflicts with tx_y, which is already in the chain, so it was dropped. Mempools: [1, 1, 1, 1, 1]
- node3 mined tx_x into a new block. Final: height 7 on every node, identical UTXO state hash `cc68399b0d8c03a7…`, all mempools empty. Erin has 45 (tx_y won), Dave has 0, Carol has 30.

## 5. Remaining responsive under malformed or repeated input (attacks on node2)

| Attack | Node reaction |
|---|---|
| Garbage bytes (bad magic) | disconnected immediately: True |
| Frame declaring 1048577 bytes (over 1 MiB limit) | disconnected before reading the body: True |
| Connect and stay silent (no `hello`) | handshake timeout after 3.0s, disconnected: True |
| 12 frames of invalid JSON | `error` replies, +10 score each, **banned** at 100: True |
| 1,500 pings in one burst (bucket 400, 200/s) | excess messages dropped, rate-limit penalties, banned: True |
| 50 repeated `inv` for a block node2 already has | 50 received, 0 `getdata` sent (duplicate suppression) |
| Block with invalid PoW, sent twice | rejected, +50 each, banned: True |

- After the attacks node2 still relays and mines: a new tx from node4 reached it, node2 mined it, and all 5 nodes converged at height 8. Bans held by node2: ['mallory-badblock', 'mallory-flood', 'mallory-json']
